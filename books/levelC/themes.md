# LevelC

This level introduces introduces dialogue and 1st/2nd person verb forms.
We do not yet introduce questions; all dialogue must be statements or imperatives.

## Grammar

- Continue using only present tense verbs and infinitives.
- **NEW**: Characters may speak in 1st/2nd person singular/plural and may use singular/plural commands.
- **NEW**: Nouns can now be in the vocative case.
- Stories should by 50-100% dialogue and narration only used to describe events when it would be awkward for dialogue.

## Vocabulary

There is minimal new vocabulary introduced since there are many new grammar forms being introduced.

Basic expressions:
- χαῖρε / χαίρετε (hello, greetings)
- ἔρρωσο / ἔρρωσθε (farewell, goodbye)
- εὐχαριστῶ (thank you)
- συγγνώμη (forgiveness, excuse me/sorry)
